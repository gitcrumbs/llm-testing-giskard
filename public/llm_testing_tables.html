Table 02
Testing Maturity Model
A practical progression from smoke tests to red teaming. Locate your team and see what's next.
Stage What you do Tooling
L1
Smoke Test
20 hand-curated questions. Verify outputs are coherent, on-topic, and not obviously wrong. Takes one afternoon. Every team should be here before shipping anything.
Manual / Spreadsheet
L2
Security Scan
Run Giskard on your wrapped model. Triage by severity. Fix critical failures before launch. Commit the generated regression test suite to your repo.
Giskard
L3
Quality Eval
For RAG: measure faithfulness, context recall, and answer relevancy. For non-RAG: answer correctness metrics. Set explicit pass/fail thresholds before running.
RAGAS DeepEval
L4
CI Integration
Giskard test suite and RAGAS evals run on every pull request touching the prompt, retrieval config, or model version. Failures block merge. Evaluation becomes automatic.
Giskard RAGAS pytest
L5
Production Obs.
Trace every production request. Monitor latency, cost, and output quality over time. Alert on regression. Sample production traffic for offline evaluation.
LangSmith Braintrust W&B
L6
Human Red Team
Domain experts systematically probe for failures no automated tool detects. Required for medical, legal, and safety-critical applications. Run at every major model or prompt change.
Human eval protocol
